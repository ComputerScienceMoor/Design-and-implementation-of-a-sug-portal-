# Design-and-implementation-of-a-sug-portal-
Oluniran Samuel Mofopefoluwa  (HNDSWD/24/015), The Student Union Government (SUG) Payment Portal with Chatbot is a web-based application designed to simplify and improve the management of Student Union Government dues at the Federal College of Animal Health and Production Technology (FCAH&PT), Moor Plantation, Ibadan, Nigeria.

The system provides a centralized platform that enables students to make SUG payments, check their payment status, and access payment-related information. It also provides an administrative dashboard that allows authorized SUG executives to monitor payment records, manage transactions, and maintain organized financial records.

An integrated chatbot provides automated responses to frequently asked questions about SUG dues, payment procedures, and payment status. When a student’s inquiry cannot be resolved automatically, the chatbot directs the student to an SUG executive for further assistance.

The project aims to reduce the challenges associated with manual payment management, minimize record-keeping errors, improve payment verification, and promote transparency and accountability in SUG financial administration.

Key Features

* Student Payment Management: Enables students to make SUG dues payments and check their payment status.
* Administrative Dashboard: Provides authorized SUG executives with access to payment records and management functions.
* Payment Tracking: Supports monitoring and verification of student payment records.
* Integrated Chatbot: Provides automatic responses to common payment-related questions.
* Human Support Escalation: Directs unresolved chatbot inquiries to SUG executives.
* Centralized Database: Stores student and payment information in an organized manner.
* User-Friendly Interface: Provides a simple and responsive interface for students and administrators.
* Improved Accountability: Supports accurate record keeping and easier monitoring of SUG dues.

Project Objectives

1. To develop a web-based platform for managing SUG dues payments at FCAH&PT.
2. To provide centralized storage and management of student payment records.
3. To simplify payment tracking and status verification.
4. To reduce errors associated with manual payment administration.
5. To improve transparency and accountability in SUG financial management.
6. To provide automated student support through an integrated chatbot.
7. To connect students with SUG executives when the chatbot cannot resolve their inquiries.

Purpose of the Project

This project is developed as an academic project for the Higher National Diploma (HND). It demonstrates the application of web development and database management technologies to address practical challenges in student union payment administration.

Installation and Setup

1. Install XAMPP on your computer.
2. Clone or download this repository into the htdocs directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Create the project database using phpMyAdmin.
5. Import the database SQL file provided in the repository.
6. Configure the database connection settings in the project.
7. Open the application in your browser using http://localhost/sug_portal/.

Note: Update the installation instructions to match the actual database filename and configuration files included in your repository.
